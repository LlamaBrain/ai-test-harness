# Archived host workflows

These procedures contain consuming-project knowledge and are excluded from the
generic `Skills/` distribution. They are retained to preserve existing workflows;
they introduce no runtime or shared-client dependency.

`BeforeTheShade/ath-smoke-fullloop/` contains the original Unity gameplay smoke.
Install it only into BeforeTheShade under the existing `ath-smoke-fullloop` name.
New project-specific gameplay smokes belong in the consuming project or its
own bridge plugin. ATH's generic fixture smoke proves the harness itself.
